# 0003. 공식 자료 불일치 시 KBL 값 우선

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
라숀 토마스의 신상 정보가 공식 자료끼리 다르다.

| 항목 | KBL | FIBA·위키백과 |
|---|---|---|
| 생년월일 | 1994-08-18 | 1994-08-15 |
| 신장 | 200cm | 203cm |

## 결정
- 선수 신상 정보(생년월일·신장·체중·등번호·포지션)가 출처마다 다르면 **KBL 공식 값을 최우선**으로 한다.
- 다른 출처의 값은 선수 `notes` 에 불일치로 기록만 한다.
- 해외 리그 경기 기록은 해당 리그 공식 페이지를 우선한다.
  - 공식 페이지를 읽을 수 없으면 신뢰할 만한 기록 사이트를 쓰고, 출처에 그 사실을 적는다.

## 결과
- 토마스는 KBL 값(1994-08-18, 200cm)을 유지한다.
