# 0007. KBL 공식 사이트 API 로 기록 수집

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
- kbl.or.kr 은 자바스크립트로 그리는 사이트라 HTML 로는 기록을 읽을 수 없다.
- 사이트가 사용하는 내부 API(공개 문서 없음)는 Origin/Referer 헤더를 붙이면 JSON 을 돌려준다.

## 결정
- `kbl2k fetch league <시즌>`: 시즌 전체 선수 기록 + 신장·체중 → `data/league/kbl-<시즌>.json`. 능력치 보정 모집단으로 쓴다.
- `kbl2k fetch players <시즌...>`: 로스터 선수별 1군 정규시즌 이력 → 팀 파일 `stats`.
  - 대상 시즌의 KBL 행만 교체하고, 해외 기록은 유지한다.
- 시즌 코드(1군)는 `2 × 시작연도 − 4003` 이다(2025-26 = 47). 짝수 코드는 D리그다.
  - 근거: API 가 47 을 '정규시즌', 48 을 'D리그' 로 표기한다.
  - 근거: 35 = 2019-20 의 43경기(코로나 조기 종료)와 일치한다.
- 요청은 최소화한다: 페이지당 200명, 선수 간 1초 지연.
- 변환 로직은 순수 함수로 두고, 가짜 응답으로 테스트한다.
- 해외 리그 기록은 수동으로 입력한다(출처 URL 필수).

## 결과
- 시즌 중 갱신이 명령 한 줄로 된다.
- 비공개 API 라 형식이 바뀌면 수집이 실패할 수 있다.
  - 이때는 변환 함수와 테스트를 먼저 고친다.
