# 0018. 팀 이름·도시·약어 — 팀 레코드 직접 쓰기 (시험)

- 상태: 승인 (시험 단계 — 저장 후 유지 여부 확인 필요)
- 날짜: 2026-10-15

## 맥락
- 정관장·SK 는 Chicago Bulls·Atlanta Hawks 자리를 쓰고 있다(ADR-0015).
- MyNBA 팀 이전(Relocation)은 미국 등 미리 정해진 도시만 고를 수 있고, 팀명을 직접 입력할 수 없다(사용자 확인).
- 2KVenueLab 은 팀명·도시·약어 쓰기를 잠가 두었다("locked in 2.1").
  - 대신 probe 코드에 팀 필드 정의가 있다.

  | 필드 | 위치(TeamRecord 기준) | 크기 |
  |---|---|---|
  | team_name | +0x2E2 | UTF-16 50B (25자) |
  | city_name | +0x314 | 36B (18자) |
  | city_short_name | +0x338 | 14B (7자) — 화면 약어 |

- 같은 고정 칸 UTF-16 방식인 선수 이름은 쓰기 → 저장 → 재로드가 성공했다.

## 결정
- 팀 데이터에 `game_identity`(영문 도시·팀명·약어)를 두고, `kbl2k venuelab apply` 가 팀 레코드에 쓴다.
  - 선수 이름과 같은 방식: 실제 이전 바이트 읽기 → 쓰기 → 다시 읽기
- 사용자 지정 이름:

  | KBL 팀 | 도시 | 팀명 | 약어 |
  |---|---|---|---|
  | 안양 정관장 | Anyang | Red Boosters | JKJ |
  | 서울 SK | Seoul | Knights | SK |

- 이름을 바꾼 뒤에도 다음 실행에서 팀을 찾도록, 교체 전 이름(`nba_slot`)과 새 이름 둘 다로 찾는다.

## 결과 / 확인할 것
- 시험 항목:
  1. 쓰기 → 저장 → 로스터 재로드 후 이름이 유지되는가
  2. 빠른 게임 팀 선택, 경기 중 점수판·해설에 반영되는가
- 일부 화면(로고, 해설 음성, 점수판 그래픽)은 다른 데이터를 써서 바뀌지 않을 수 있다.
- 유지되지 않으면 이 ADR 을 '실패'로 바꾸고 다른 방법을 찾는다.

## 시험 결과 (2026-10-15)
- 쓰기: 두 팀 × 3필드, 6개 모두 성공(readback 확인). 같은 이름의 클래식 팀은 건드리지 않았다.
- 저장: 커스텀 로스터 `RosterNBA0001` 에 저장했다. 게임 화면에 Anyang Red Boosters / Seoul Knights 로 표시된다(사용자 확인).
- 남은 확인:
  - 로스터 재로드 후 유지
  - 빠른 게임 팀 선택 화면
  - 경기 중 점수판(약어)
