# 0008. 해외 리그 보정값

- 상태: 승인 (잠정값 — 게임 내 확인 후 조정)
- 날짜: 2026-10-14

## 맥락
신규 외국인 선수는 2025-26 KBL 기록이 없어 해외 리그 기록으로 능력치를 산정한다.
같은 기록이라도 리그 수준이 다르다.

## 결정
`rating_rules.json` 의 `league_offsets` 값을 다음과 같이 정한다(능력치 점수).

| 리그 (`stats.league`) | 보정 |
|---|---|
| KBL | 0 (기준) |
| B.League B1 | +2 |
| B.League B2 | −3 |
| LBA (이탈리아 세리에A) | +4 |
| FIBA Europe Cup | +2 |

- 보정은 사용된 구성요소 중 **기록 지표 가중치 비율만큼만** 더한다.
  - 신장·체중만으로 정해지는 능력치(Speed, Agility, Strength 등)는 영향을 받지 않는다.
- 보정값이 없는 리그는 0 으로 계산하고, 검증에서 경고한다.

## 결과
- 새 리그 기록을 넣을 때 이 표에 값을 추가해야 경고가 사라진다.
