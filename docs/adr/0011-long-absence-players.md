# 0011. 장기 미출전 국내 선수 처리

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
일부 국내 선수는 최근 KBL 1군 기록이 없거나 오래되었다. 상무 복무 등으로 보인다(사유 미확인).

| 선수 | 능력치 기준 |
|---|---|
| 김수환(SK) | 2021-22 ~ 2025-26 KBL 기록 없음 → 신장·체중만 |
| 김세창(정관장) | 2022-23 KBL |
| 임현택(SK) | 2022-23 KBL |
| 김진영(정관장) | 2023-24 KBL |

## 결정
- 현재 자동 규칙을 그대로 쓴다.
  - 가장 최근의 KBL 기록을 쓴다.
  - 기록이 없으면 신장·체중 기반 능력치와 기본값을 쓴다.
- 추정치를 만들지 않는다. D리그·상무 기록도 쓰지 않는다.
- 2026-27 시즌 출전 기록이 쌓이면 `kbl2k fetch players 2026-27 ...` 로 갱신해 재산정한다.
- 체감이 맞지 않으면 `ratings_override` 로 개별 보정한다.

## 결과
- 이 선수들은 실제보다 낮거나 평균에 가깝게 나올 수 있다.
