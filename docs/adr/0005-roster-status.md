# 0005. 부상·대체 선수 표현

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
정관장은 외국인 2명(존 무니, 라숀 토마스)으로 운영한다.
토마스가 골타박상으로 약 2주 결장해, 데이본 리드를 일시 대체 외국인으로 영입했다(사용자 제보).
KBL 현역 명단에는 세 명이 모두 올라 있다.

## 결정
- 선수에 선택 필드 `roster_status` 를 둔다. 생략하면 `active` 다.
  - `state`: `active` / `injured` / `replacement`
  - `replaces`: 대체 대상 선수 id. `replacement` 일 때만 필수이고, 그 외에는 금지한다.
  - `since`, `expected_return`, `note`
- 검증 규칙:
  - 대체 대상이 같은 팀에 없으면 오류
  - 자기 자신을 대체하면 오류
  - 대체 대상이 `injured` 가 아니면 경고
- 현재 적용:
  - 토마스 = `injured` (시작일·복귀일 미상이라 null)
  - 리드 = `replacement`, `replaces: kgc-rashawn-thomas`

## 결과
- 게임 반영 시 부상자 설정, 로스터 인원 제한 처리에 이 정보를 쓴다.
- 토마스가 복귀하면 상태를 갱신해야 한다.
