# 0015. 게임 반영 방식 — NBA 팀 2개 교체, 15명 수동 선발, 능력치 확장, 영문 이름

- 상태: 승인 (교체할 NBA 팀과 선발 명단은 별도 지정)
- 날짜: 2026-10-15

## 맥락
- 2KVenueLab 은 새 선수를 만들 수 없고 기존 선수 레코드를 덮어쓴다(ADR-0014).
- 2K 팀 로스터는 15명이다. KBL 등록 인원은 정관장 19명, SK 20명이다.
- 2K26 선수 레코드에는 능력치가 52종 있다(docs/2k26-player-fields.md). 우리 모델은 22종이다.
- 2K 글꼴의 한글 지원 여부는 확인하지 않았다.

## 결정
1. **NBA 팀 2개를 통째로 교체한다.**
   - 각 팀의 15명을 KBL 선수로 덮어쓴다.
   - 팀 이름·도시·색은 게임의 팀 이전/브랜딩 기능으로 정관장·SK 로 바꾼다.
   - 덮어쓴 NBA 선수는 그 MyNBA 세이브에서 사라진다(해당 세이브에 한정).
2. **팀당 15명은 사용자가 직접 고른다.**
   - 팀 파일에 `game_roster`(선수 id 목록, 최대 15)로 기록한다.
3. **추가 능력치**
   - 기록으로 산정할 수 있는 항목은 모델에 추가한다. 예: 파울 유도=자유투 시도, 패스 IQ=어시스트·턴오버, 포스트 무브=신장·득점
   - 기록으로 알 수 없는 항목(내구도·잠재력·일관성 등)은 고정 기본값을 쓴다. 기본값은 rating_rules.json 에 둔다.
4. **게임 안 이름은 영문**으로 쓴다. KBL 공식 영문명을 정리해 쓴다(예: `KIM NAK HYEON` → `Nakhyeon Kim` 형태).

## 결과
- 교체할 NBA 팀 2개와 선발 15명은 사용자가 지정한다.
- 이후 `kbl2k venuelab` 일괄 입력 도구가 `game_roster` 와 확장된 능력치를 사용한다.

## 지정 결과 (2026-10-15, 사용자)
| KBL 팀 | 교체할 NBA 팀 (`nba_slot`) | 제외 선수 |
|---|---|---|
| 안양 정관장 | Chicago Bulls | 김진영, 송한준, 주현우, 김준형 |
| 서울 SK | Atlanta Hawks | 안성우, 김명진, 전성환, 임현택, 김수환 |

- 각 팀의 나머지 15명을 `game_roster` 에 기록했다.

## 능력치 확장 (2026-10-15)
- 능력치를 22종에서 37종으로 늘렸다. 2K26 로스터 필드 52개를 모두 덮는다(Durability 1종 → 부위별 16개 필드).
- 기록으로 산정하는 항목:

| 항목 | 입력 |
|---|---|
| Post Fade | 야투율, 득점, 신장 |
| Post Hook | 신장, 야투율, 득점 |
| Draw Foul | 자유투 시도, 득점 |
| Pass IQ | 어시스트, 턴오버(−) |
| Pass Vision | 어시스트 |
| Hands | 턴오버(−), 야투율 |
| Pass Perception | 스틸 |
| Help Defense IQ | 블록, 수비리바운드, 스틸 |
| Shot IQ | 야투율, 3P%, FT% |
| Offensive Consistency | 득점, 출전시간 |
| Defensive Consistency | 스틸, 블록, 출전시간 |
| Hustle | 공격리바운드, 스틸, 출전시간 |

- 평균·표준편차는 2025-26 KBL 133명으로 다시 보정했다(`kbl2k calibrate`).
- 고정 기본값(잠정): Intangibles 60, Potential 65, Durability 80
  - `ratings_override` 로 선수별로 바꿀 수 있다.
