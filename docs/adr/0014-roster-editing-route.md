# 0014. 로스터 편집 경로 — 파일 기반 자체 도구는 중단

- 상태: 승인 대기 (대안 선택 필요)
- 날짜: 2026-10-15

## 맥락
- 사용자는 수기 입력을 원하지 않는다.
- 2K26 로스터 에디터 중 실제로 동작하는 것은 2KVenueLab 2.15 하나다.
  - 2KVenueLab 은 실행 중인 게임의 메모리를 편집한다.
  - 그래서 EAC(Easy Anti-Cheat)를 끄고 오프라인으로 실행해야 한다.
  - 이 계정은 MyTEAM 등 온라인 사용 이력이 있어 이용약관·제재 위험이 있다.
- 사용자는 EAC 를 건드리지 않는 "파일 형식 분석 → 자체 도구"를 선택했다.

## 조사 결과 (2026-10-15, 이 PC 의 세이브 직접 확인)
- 세이브 폴더 `userdata\<SteamID>\3472040\remote` 의 11개 파일이 **모두** 같은 형식이다.
  - 예: `UserData`, `Settings`, `CreatedPlayers`, `MyCAREER0001`, `RosterDescriptions`
- 형식:
  ```
  0x00  "EBNH"              매직
  0x04  00 00 00 00
  0x08  8바이트             파일마다 다름 (IV/nonce 추정)
  0x10  8바이트             3종류 값만 관찰됨 (키 ID 또는 파일 유형 추정)
  0x18~ 본문                엔트로피 7.95~8.00 bit/byte → 암호화
  ```
- 모든 파일 크기가 8의 배수다 → 블록 암호로 추정된다.
- `EBNH` 형식에 대한 공개 자료는 찾지 못했다.

## 결정
- 파일 기반 자체 로스터 편집기 개발은 **중단**한다. 이유:
  1. 세이브(로스터 포함)를 편집하려면 암호화를 해제해야 한다. 키는 EAC 로 보호된 게임 실행 파일 안에 있다.
  2. 키를 얻으려면 실행 파일·프로세스를 분석해야 하고, 결국 EAC 비활성화가 필요하다.
     - EAC 를 건드리지 않는다는 목적을 이룰 수 없다.
  3. 게임의 보호 장치(암호화)를 깨는 일은 이용약관·법적 위험이 메모리 편집보다 크다.
  4. 성공을 보장할 수 없다(원칙: 검증되지 않은 포맷을 임의로 만들지 않는다).
- Claude 는 EAC 우회나 세이브 암호 해제 방법을 만들거나 안내하지 않는다.

## 남은 선택지 (사용자 결정 필요)
1. 2KVenueLab 사용. EAC 를 끄는 방법은 제작자 안내를 사용자가 직접 따른다. 편집은 인터넷을 끊고 한다.
2. 인게임 편집(수기). 사용자가 제외했다.
3. 보류. 2K26 용 파일 기반·공식 도구가 나오거나 EAC 와 함께 쓸 수 있는 방법이 생길 때까지 기다린다.
   - 그동안 데이터 파이프라인과 비주얼(mods 폴더 방식, EAC 무관)을 먼저 진행한다.

## 결과
- 로스터 반영 단계(PLAN 4단계)는 위 선택이 날 때까지 대기한다.
