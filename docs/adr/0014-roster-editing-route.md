# 0014. 로스터 편집 경로 — 파일 기반 자체 도구 중단, 공식 오프라인 실행 확인

- 상태: 승인 — 경로 1 선택 (2026-10-15)
- 날짜: 2026-10-15

## 맥락
- 사용자는 수기 입력을 원하지 않는다.
- 2K26 로스터 에디터 중 실제로 동작하는 것은 2KVenueLab 2.15(메모리 편집) 하나다.
  - EAC 가 켜져 있으면 동작하지 않는다.

## 조사 결과 (2026-10-15)
1. **세이브는 암호화되어 있다** (이 PC 의 `remote` 폴더 11개 파일 직접 확인).
   ```
   0x00  "EBNH"  | 0x04 00000000 | 0x08 8B 파일별 상이(IV 추정) | 0x10 8B 3종(키 ID 추정)
   0x18~ 본문: 엔트로피 7.95~8.00, 파일 크기 8의 배수 → 블록 암호 추정
   ```
   - 공개 자료가 없다. 키는 게임 실행 파일 안에 있을 것이다.
2. **EAC 없는 실행은 공식 옵션이다** (이 PC 의 Steam `appinfo.vdf` 직접 확인).
   - 기본: `start_protected_game.exe` — "Play NBA 2K26"
   - option1: `NBA2K26.exe` — **"NBA 2K26 without EAC (offline only)"**
   - Steam 에서 실행할 때 고를 수 있다. 우회나 파일 조작이 필요 없다.
   - 2K25 패치 3.0 에서 같은 옵션이 생겼다는 커뮤니티 정보와 일치한다.
3. 국내외 사례:
   - 최신작 KBL 사례는 찾지 못했다(국내는 2K11~2K14 의 PC 파일 교체 방식만 확인).
   - 해외 대형 변환 모드(PCBasket 2K26 EuroLeague 등)도 PC 모드와 오프라인 전제로 보인다.
   - EAC 를 켠 채 할 수 있는 길은 게임 안 편집뿐이다.
     - 생성 선수, 커스텀 로스터, MyNBA 확장팀, 2K Share
     - CSV 일괄 입력 수단은 없다.

## 결정
- 파일 기반 자체 로스터 편집기(세이브 암호 해제)는 **중단**한다.
  - 게임 보호 장치를 깨는 일이라 위험이 크고, 성공도 보장할 수 없다.
- Claude 는 세이브 암호 해제나 EAC 우회 방법을 만들지 않는다.
  - 공식 "without EAC (offline only)" 실행 옵션은 우회가 아니므로 사용 대상에서 제외하지 않는다.

## 경로 후보 → 사용자가 1번 선택
1. **공식 오프라인 실행 + 2KVenueLab** (권장)
   - Steam 에서 "NBA 2K26 without EAC (offline only)" 로 실행한다.
   - MyNBA 확장팀 2개를 정관장·SK 로 만들고, 확장팀 선수를 KBL 선수로 덮어쓴다.
   - 남은 위험: 제3자 메모리 편집 도구 사용 자체(오프라인 한정). 온라인 모드에서는 절대 쓰지 않는다.
2. EAC 켠 상태의 게임 안 편집
   - 생성 선수 → 커스텀 로스터 → MyNBA, 확장팀으로 팀 정체성을 만든다.
   - 위험은 없지만 전부 수기 입력이다.

## 결과
- 사용자가 경로 1(공식 오프라인 실행 + 2KVenueLab)을 선택했다.
- 진행 순서:
  1. 사용자가 NLSC 포럼에서 직접 다운로드한다.
  2. Claude 가 MD5(`fb5e5bc97ce31d85de60093520b3711b`) 대조, Defender 검사, 압축 내용을 점검한다(실행하지 않음).
  3. `kbl2k game snapshot` 으로 게임 폴더·세이브 폴더 기준을 만든다.
  4. 사용자가 "without EAC (offline only)" 로 실행하고 인터넷을 끊은 뒤 ADR-0013 검증 항목을 수행한다.
  5. `kbl2k game diff` 로 변경 확인 → 검증 통과 시 확장팀 2개에 KBL 로스터를 반영한다.
- 일괄 입력 수단은 프로그램을 받은 뒤 분석한다.

## 변경 (2026-10-15, 사용자 결정): 인터넷 연결 유지 허용
- 처음에는 예방책으로 "인터넷 끊기"를 권했다. 이는 게임이 요구하는 조건이 아니었다.
- Steam "without EAC (offline only)" 모드는 그 자체로 오프라인 전용이다. 우리 일괄 입력 도구는 네트워크를 쓰지 않는다.
- 사용자 결정: **인터넷을 연결한 채로 작업한다.** 진행 중 Claude 와 실시간으로 소통하기 위해서다.
- 지킬 것:
  - 이 모드에서 온라인 모드(MyCAREER 온라인, MyTEAM 등)에 들어가지 않는다.
  - 작업 후 게임을 완전히 종료한다. 온라인은 기본 "Play NBA 2K26"(EAC 켜짐)으로만 실행한다.
