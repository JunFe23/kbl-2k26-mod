# 0013. 로스터 에디터 검증 절차

- 상태: 승인
- 날짜: 2026-10-14 (승인 2026-10-15)

## 맥락
- 2K26 로스터 에디터 후보(2KVenueLab, Immerse 등)는 비공개 소스다. NLSC 포럼·Ko-fi·Discord 로 배포된다.
- 프로젝트 원칙상 외부 도구의 호환성은 반드시 검증해야 한다.
- 이 PC 의 게임 상태(2026-10-14):
  - Steam 빌드 24237529, 기존 모드 없음
  - 게임 폴더의 `mod.exe` 는 서명이 없고 정체를 모른다
  - 세이브는 Steam 클라우드 동기화 폴더에 저장된다
  - 계정은 온라인 모드(MyTEAM 등) 사용 이력이 있다

## 결정
1. **다운로드와 실행은 사용자가 직접 한다.** Claude 는 외부 실행 파일을 내려받거나 실행하지 않는다.
   - 대신 파일 해시·서명 확인과 결과 분석을 맡는다.
2. 도구를 쓰기 **전**에 기준 스냅샷을 만든다.
   - 게임 폴더: `kbl2k game snapshot --label before-<도구>`
   - 세이브 폴더: `kbl2k game snapshot --dir <userdata 경로> --label before-<도구>-save`
3. 도구를 쓴 **후**에는 `kbl2k game diff` 로 실제 변경 파일을 확인한다.
   - 아카이브(0A~)나 exe 가 바뀌면 즉시 Steam '파일 무결성 검사'로 복구하고 그 도구를 쓰지 않는다.
4. 검증은 **새 MyNBA 세이브 + 오프라인** 상태에서만 한다.
   - 메모리 편집형 도구는 온라인 접속 중에 절대 쓰지 않는다.
5. 검증 항목:
   - (a) 도구가 빌드 24237529 를 인식하는가
   - (b) 선수 1명의 이름·능력치를 바꾸고 저장·재시작 후 유지되는가
   - (c) 가져오기(import) 포맷이 있다면 그 실제 형식
   - (d) 팀 이름·약어 변경 가능 여부
   - (e) 2K 능력치 목록과 우리 22개 속성 이름 대조
6. 결과는 `docs/modding-tools.md` 검증 표에 기록한다. 통과한 도구만 어댑터(`kbl2k export <도구>`) 대상으로 삼는다.

## 결과
- 도구가 게임 폴더를 몰래 바꾸는지 객관적으로 확인할 수 있다.
- 게임 업데이트(빌드 변경)도 스냅샷 비교로 감지된다. 업데이트되면 검증을 다시 한다.
