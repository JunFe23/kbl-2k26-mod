# 0010. 능력치 산정 모델

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
선수별 기록과 신체 정보로 2K26 능력치 22종과 OVR 을 일관되게 만들어야 한다.
계수는 코드 수정 없이 조정할 수 있어야 한다.

## 결정
- 능력치 하나는 다음과 같이 계산한다.
  ```
  능력치 = clamp(base + spread·z + league_offset + 리그보정×기록비중 + 포지션보정, 25, 99)
  ```
- z 는 구성 입력(기록·신장·체중) z-score 의 가중 평균이다. ±z_cap 에서 자른다.
- 표본 축소:
  - 출전 경기 < `min_games`(20) 이면 기록 z 에 경기 수 / 20 을 곱한다.
  - 성공률 지표는 시도 수가 적으면 z 를 줄인다.
- 기록 자동 선택 순서:
  1. 20경기 이상
  2. 기준 시즌(2025-26) → 최신 시즌
  3. KBL > 해외, 정규시즌 > 컵, 경기 수 많은 순
  - `rating_basis` 로 직접 지정할 수 있다.
- 평균·표준편차는 **2025-26 KBL 정규리그 20경기 이상 출전자 133명**(기록·신장·체중)으로 보정했다(`kbl2k calibrate`).
- OVR 은 포지션별 핵심 능력치의 가중 평균이다.
- 수동 보정 `ratings_override` 가 계산값보다 우선한다.
- 모든 계수는 `data/rules/rating_rules.json` 에 둔다.

## 결과
- 시즌이 바뀌면 `fetch league` → `calibrate` 로 기준을 갱신할 수 있다.
- 2K 엔진의 실제 체감과는 게임 내 테스트로 맞춰야 한다(ADR-0012).
