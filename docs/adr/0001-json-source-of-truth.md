# 0001. JSON 원천 데이터와 게임 파일 비수정 원칙

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
NBA 2K26 PC 모딩 도구는 대부분 비공개 소스이고, 로스터 입출력 포맷이 공개되어 있지 않다(docs/modding-tools.md).
게임 패치가 수정 파일을 덮어쓸 수 있고, 온라인에서 쓰면 Easy Anti-Cheat 제재 위험이 있다.

## 결정
- 선수·팀·능력치·에셋 매핑의 원천은 `data/` 아래 JSON 이다. JSON Schema(draft 2020-12)로 형식을 강제한다.
- 원본 게임 파일은 직접 수정하지 않는다.
- 불가피하게 게임 파일을 바꿀 때는 다음 순서를 지킨다.
  1. `kbl2k backup` (게임 폴더 밖에 SHA-256 manifest 와 함께 저장)
  2. 적용
  3. `kbl2k restore` 리허설
- 게임 반영은 로스터 에디터를 검증한 뒤 별도 어댑터로 구현한다.
- 모든 모드 테스트는 오프라인에서만 한다.

## 결과
- 도구가 바뀌어도 데이터는 그대로 쓸 수 있다.
- 게임 반영 단계에서 어댑터를 추가로 만들어야 한다.
