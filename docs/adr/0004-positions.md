# 0004. KBL 포지션과 2K 포지션 분리

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
- KBL 은 포지션을 가드/포워드/센터(G/F/C)로만 공시한다.
- 2K 시리즈 로스터는 PG/SG/SF/PF/C 와 주·보조 포지션 체계다.
- 2K 포지션을 KBL 표기에서 자동으로 정하면 사실이 아닌 값을 만드는 셈이다.

## 결정
- `position_kbl` (G/F/C): KBL 공식 표기, 사실 데이터로 다룬다.
- `positions` (최대 2개, `[주, 보조]`): 2K26 에 넣을 값으로, 사용자가 직접 정하는 모드 설계값이다.
- 입력은 `kbl2k positions export` → 엑셀 편집 → `kbl2k positions import` 로 한다.
  - CSV 에 오류가 하나라도 있으면 아무것도 반영하지 않는다.
- KBL 표기와 맞지 않는 주 포지션(예: F → C)은 경고만 하고 허용한다.
- 2K26 이 5포지션 체계인지는 로스터 에디터 확정 후 최종 확인한다.

## 결과
- 포지션 보정(능력치 position_bonus)과 포지션별 OVR 가중치는 `positions` 를 입력해야 적용된다.
