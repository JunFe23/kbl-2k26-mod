# 0017. 능력치 기록 기준 — 다시즌 가중 평균 (올 시즌 포함)

- 상태: 승인
- 날짜: 2026-10-15

## 맥락
- 기존 모델은 2025-26 한 시즌 기록만 썼다(ADR-0010).
  - 그래서 공백이나 부상 뒤 복귀 시즌인 선수가 낮게 나왔다.
  - 예: 변준형은 2023-24 공백, 2024-25 24경기였다. 사용자가 게임에서 직접 올렸다(ADR-0015 보충).
- 2026-27 시즌이 시작되었다(2026-10-15 기준 정관장 5경기, SK 0경기 — SK 첫 경기 10/18).
  - 표본은 작지만 반영할 필요가 있다.

## 결정
- 선수별 능력치 입력은 **최근 5시즌 정규시즌 기록의 가중 평균**으로 한다(`rating_rules.blend`).
  - 시즌 가중치(올 시즌 기준): 2026-27 ×4, 2025-26 ×3, 2024-25 ×2, 2023-24 ×1, 2022-23 ×1
  - 기록 가중치 = 시즌 가중치 × 출전 경기 수. 그래서 올 시즌 비중은 경기가 쌓일수록 커진다.
  - 성공률은 시도 수까지 곱해 평균한다.
    - 3P% → 3점 시도
    - FT% → 자유투 시도
    - FG% → 출전시간
  - 컵대회 기록은 제외한다(정규시즌만).
  - 표본 축소(min_games)는 사용된 시즌의 경기 수 합계로 판단한다.
  - 해외 리그 보정은 기록 비중대로 평균해 적용한다.
- 예외는 그대로 둔다.
  - `rating_basis` 지정 선수는 그 기록 하나만 쓴다(데이본 리드).
  - 명시적 시즌 지정(`--season`)은 단일 시즌을 쓴다.
  - `ratings_override` 가 계속 우선한다(변준형).
- 평균·표준편차 기준(calibrate)은 2025-26 리그 전체 133명을 그대로 쓴다.
- 시즌 중 갱신 절차:
  1. `kbl2k fetch players 2026-27 …`
  2. `kbl2k venuelab plan` → `apply --apply` → 저장
