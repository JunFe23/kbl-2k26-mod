# 0006. 공개 저장소, noreply 이메일, 에셋 비공개

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
처음에는 private 저장소를 계획했으나, 사용자가 PUBLIC 공개를 선택했다.

## 결정
- 저장소: https://github.com/JunFe23/kbl-2k26-mod (public)
- 커밋 작성자 이메일은 GitHub noreply 주소를 쓴다. 이 저장소의 로컬 git 설정이다.
  - 공개 전 기존 커밋도 noreply 로 재작성했다.
- KBL·구단 로고, 유니폼, 선수 얼굴 텍스처 등 상표권·초상권 에셋은 공개 저장소에 올리지 않는다.
  - 작업 폴더는 `assets_private/` 이다.
  - 이미지(`*.png`, `*.psd`, `*.tga`)와 게임 파일(`*.iff`, `*.ROS`)은 `.gitignore` 로 차단한다.

## 결과
- 코드와 데이터 파이프라인은 공개된다.
- 에셋 배포 방식은 저작권 검토 후 따로 결정한다(PLAN 6단계).
