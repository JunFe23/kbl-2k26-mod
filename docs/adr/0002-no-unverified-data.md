# 0002. 미검증 데이터 금지와 출처 필수

- 상태: 승인
- 날짜: 2026-10-14

## 맥락
프로젝트 원칙: "검증되지 않은 선수 정보나 파일 포맷을 임의로 만들어내지 않는다."

## 결정
- 모르는 값은 `null` 로 둔다. 추정값을 넣지 않는다.
- `verification.status: verified` 이려면 다음이 필요하다(스키마로 강제).
  - `sources` 에 출처가 1개 이상
  - `checked_at` 에 확인 날짜
- 모든 출처는 `data/sources.json` 에 등록한다. 검증기는 등록되지 않은 출처 ID 를 오류로 처리한다.
- 공식 웹 출처가 없는 정보(사용자 제보)는 `url: null`, `official: false` 출처로 등록한다.
  - 예: `user-report-2026-10-14` (토마스 부상, 리드 대체, 프레디 국적)
- `official: true` 출처는 URL 이 필수다.
- 2K26 파일명·ID 규칙은 게임에서 확인하기 전까지 스키마에서 강제하지 않는다.
- 2K26 능력치 이름은 확인된 22종만 쓴다.

## 결과
- 데이터 신뢰도를 출처 단위로 추적할 수 있다.
- 빈 값이 많아질 수 있지만, 틀린 값보다 낫다.
