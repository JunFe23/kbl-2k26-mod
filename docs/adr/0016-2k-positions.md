# 0016. 2K 포지션 지정 — 규칙 제안 + 사용자 수정, 게임 안 수동 입력

- 상태: 승인
- 날짜: 2026-10-15

## 맥락
- ADR-0004 에 따라 2K 포지션(`positions`)은 사용자가 정하는 설계값이다.
- 2KVenueLab 2.15 의 2K26 선수 필드에는 포지션이 없다. 블루프린트·쓰기 목록에도 없고, 코드의 position 은 코칭스태프 직책이다.
  - 그래서 현재 게임에는 덮어쓴 NBA 선수의 포지션이 남아 있다.

## 결정
1. 제안 규칙으로 포지션을 정하고, 사용자가 수정한 것만 바꾼다.
   - G: 어시스트 3.0 이상 또는 183cm 이하 → PG, 그 외 SG. 보조는 PG↔SG, 193cm 이상 SG 는 SF
   - F: 197cm 미만 → SF, 이상 → PF. 보조는 SF→PF(193cm 이하는 SG), PF→C(200cm 이상) 또는 SF
   - C: C / PF
   - 사용자 수정: **이대헌 PF/SF** (2026-10-15)
2. 데이터 반영은 `kbl2k positions import` 로 한다(30명).
3. 게임 반영은 게임 안 선수 편집에서 **수동 입력**한다. 30명 × 주/보조 포지션이다.
   - 수동 입력 후 커스텀 로스터를 다시 저장한다.

## 결과
- 포지션 보정(position_bonus)과 포지션별 OVR 가중치가 적용되어 능력치가 일부 바뀐다.
  - 게임에 능력치를 다시 써야 한다: `kbl2k venuelab plan` → `apply --apply`
- VenueLab 이 포지션 쓰기를 지원하면 자동화한다.
